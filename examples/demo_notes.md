# RAGX Demo Notes

RAGX is an Adaptive Multi-RAG Orchestrator. It analyzes heterogeneous datasets and selects the right retrieval architecture for each part of the data.

Semantic RAG handles unstructured content such as PDF reports, DOCX documents, Markdown notes, website pages, and plain text.

SQL RAG handles structured analytical tables such as CSV and XLSX files. It translates natural language questions into read-only SQLite queries and displays the generated SQL.

The graph layer extracts prominent entities and relationship hints. It is useful when users ask about dependencies, links, and relationships between concepts.

The product is designed for hackathon demos where clarity, reliability, and explainability matter.
